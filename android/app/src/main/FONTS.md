# Fonts

`res/font/misans_vf.ttf` is MiSans by Xiaomi, used under the MiSans font licence (free for
commercial use when the software notes that it uses MiSans). The font file is not covered by this
repository's licence. https://hyperos.mi.com/font/en/

It is the variable font, unmodified; `ui/Theme.kt` sets its weights. This note sits here rather than
in `res/font/`, where Android accepts nothing but fonts and font XML.
